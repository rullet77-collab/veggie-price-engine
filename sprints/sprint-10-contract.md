# 스프린트 S10: 판매가 인라인 수정 + 확정

## 목표
전체상품 테이블에서 판매가를 직접 수정하고 확정 버튼으로 DB에 저장할 수 있도록 한다.

## 구현 범위
- [ ] 판매가 셀 클릭 → 인라인 편집 모드
- [ ] 수익률 자동 재계산 (편집 시 실시간)
- [ ] 확정 버튼 → DB 저장 API
- [ ] 추천가 표시 + 이상치 하이라이트 (S11 병합)
- [ ] 상품그룹 동조화 보조 UI (S12 병합)

## 합격 조건
1. 판매가 셀 클릭 → 수정 → 확정 → DB 저장 확인
2. 수정 시 수익률이 실시간 재계산됨
3. 추천가 열이 표시되고 급등/급락 하이라이트
