# 스프린트 S02: 엑셀 업로드 API (천년경영 → DB)

## 목표
천년경영 프로그램에서 다운로드한 매입상세/매출상세 엑셀 파일을 웹에서 드래그앤드롭으로 업로드하면 Supabase DB에 자동 저장되도록 한다.

## 구현 범위
- [ ] 엑셀 파싱 라이브러리 설치 (xlsx)
- [ ] 업로드 페이지 UI (/upload)
- [ ] 매입상세 엑셀 파싱 → daily_purchase_prices INSERT API
- [ ] 매출상세 엑셀 파싱 → daily_selling_prices INSERT API
- [ ] 업로드 결과 표시 (성공/실패 건수)

## 제외 범위
- 상품 마스터 자동 등록 (이미 838개 등록됨)
- 플랫폼별 업로드 파일 생성 — S13 이후

## 합격 조건
1. /upload 페이지에서 매입상세 엑셀을 드래그앤드롭하면 daily_purchase_prices에 데이터가 저장됨
2. 매출상세 엑셀도 동일하게 동작
3. 중복 데이터는 ON CONFLICT로 안전하게 처리
4. 업로드 후 성공/실패 건수가 화면에 표시됨
