# 스프린트 S01: Next.js 프로젝트 생성 + Supabase 연동

## 목표
Next.js 프로젝트를 생성하고 Supabase와 연동하여, 빈 대시보드 페이지가 localhost:3000에서 열리는 것을 확인한다.

## 구현 범위
- [ ] Next.js 프로젝트 생성 (App Router + TypeScript + Tailwind CSS)
- [ ] Supabase 클라이언트 설정 (@supabase/supabase-js)
- [ ] 환경변수 설정 (.env.local)
- [ ] 메인 대시보드 페이지 (빈 레이아웃 + DB 연결 확인)
- [ ] GitHub 리포지토리 생성 + push
