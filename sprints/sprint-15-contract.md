# 스프린트 S15: 신선행 API 연동

## 목표
신선행(자사 시스템)에 판매가를 API로 직접 전송할 수 있도록 한다.

## 구현 범위
- [ ] /api/platform/sinsunhang POST → 신선행 판매가 데이터 조회/전송 준비
- [ ] 신선행 판매가 = MAX(식봄가 × 0.94, 매입가 ÷ 0.9)
- [ ] 전송 대상 상품 목록 + 가격 미리보기

## 합격 조건
1. 신선행 판매가가 올바르게 계산됨
2. 전송 대상 상품 목록이 JSON으로 반환됨
3. 식봄 수익률 11.1% 미만 시 하한선(매입가/0.9)이 적용됨
