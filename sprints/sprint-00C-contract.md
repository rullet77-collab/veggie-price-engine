# 스프린트 S00-C: 점수화 + 추천가 백테스트

## 목표
S00-B에서 만든 신호 해석층 위에 전략 선택층(점수화)과 가격 산출층을 구현하고, 2025년 실제 판매가와 비교하여 엔진의 유효성을 검증한다.

## 구현 범위
- [ ] 매출 추이 분석 함수 (직전3개월 평균 매출 vs 당월)
- [ ] 전략 선택층: 신호 → 점수 변환 → 정책 선택 (마진방어/현상유지/점유율확대/공격적인하)
- [ ] 가격 산출층: 기준매입가 + 추천수익률 → 추천판매가 산출
- [ ] 통합 백테스트: 엔진 추천가 vs 실제 판매가 비교 리포트

## 제외 범위
- 품목군별 파라미터 튜닝 — S00-D에서 수행
- 웹 UI — S09 이후

## 합격 조건
1. 점수화 시스템이 기획서 섹션 7.4의 신호→점수 변환표와 일치
2. 추천가 산출이 기획서 섹션 2.1의 수식(ROUNDUP, 10원단위 올림)과 정확히 일치
3. 엔진 추천가와 실제 판매가의 **방향 일치율 80% 이상**, **가격 괴리 ±5% 이내 70% 이상**

## 참조 자료
- 기획서 섹션 2.1: 판매가 계산 공식
- 기획서 섹션 2.2: 규칙 1~8
- 기획서 섹션 7.4: 점수화 시스템
- 기획서 섹션 7.6: 백테스트 성공 기준
