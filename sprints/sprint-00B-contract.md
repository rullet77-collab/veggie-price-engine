# 스프린트 S00-B: 신호 해석층 백테스트

## 목표
2025년 매입가 데이터로 신호 해석층(Signal Layer)의 추세/변곡점/변동성을 산출하고, 형민님이 "이 판정이 맞다"고 확인할 수 있는 리포트를 생성한다.

## 구현 범위
- [ ] 신호 해석층 SQL 함수 구현 (Supabase PostgreSQL)
  - 8일 절사평균 동향 (급등/상승/보합/하락/급락 5단계)
  - 최근 3일 추세 방향 및 지속 일수
  - 변곡점 매입가 (박스권 이탈 시점)
  - 7일 변동성 수준 (표준편차/평균 기반 CV)
  - 7일 최고가/중앙값/가중평균
- [ ] 백테스트 실행: 주요 경쟁 품목 대상으로 2025년 전 기간 신호 산출
- [ ] 검증 리포트 생성: 가지 그룹 3월 데이터로 신호 판정 결과 확인

## 제외 범위
- 전략 선택층 (점수화) — S00-C에서 구현
- 추천 판매가 산출 — S00-C에서 구현
- 매출 추이 분석 — S00-C에서 구현
- 웹 UI — S09 이후

## 합격 조건 (Acceptance Criteria)
1. **절사평균 동향 일치**: 8일 매입가 기반 절사평균 5단계 판정이 기획서 섹션 2.1의 로직과 정확히 일치
   - 변동률 기준: +20% 초과=급등, +3%~+20%=상승, ±3%=보합, -3%~-20%=하락, -20% 초과=급락
   - 매입 4일 미만 시 계산 제외
2. **변곡점 탐지**: 가지 그룹 3월 데이터에서 3/7-8 급등, 3/15-18 급락 변곡점이 탐지됨
3. **리포트 가독성**: 상품별 일별 신호 결과를 형민님이 확인 가능한 형태로 출력

## 참조 자료
- 기획서 섹션 2.1: 절사평균 동향 분석 로직
- 기획서 섹션 7.2~7.3: 신호 해석층 설계
- 기획서 섹션 7.8: 가지 그룹 3월 실데이터

## 검증 방법
- SQL 쿼리로 가지/상(005045), 가지/특(003362) 3월 데이터에서 신호 산출 → 기획서 7.8 실데이터와 대조
- 주요 경쟁 품목 9개에 대해 전체 기간 신호 산출 → 이상치 없는지 확인
