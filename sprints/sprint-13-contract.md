# 스프린트 S13: 식봄 업로드 엑셀 생성

## 목표
확정된 판매가 데이터를 식봄 플랫폼 업로드 양식에 맞는 엑셀 파일로 생성/다운로드한다.

## 구현 범위
- [ ] /api/platform/sikbom GET → 식봄 업로드용 엑셀 생성
- [ ] 컬럼: 상품코드, 상품명, 규격, 판매가, 정상가(행사품목), 행사여부
- [ ] 행사품목: 판매가 × 1.25 = 정상가
- [ ] 금액 10원 단위 올림 (ROUNDUP -1)

## 합격 조건
1. API 호출 시 .xlsx 파일이 정상 다운로드됨
2. 행사품목의 정상가가 판매가 × 1.25로 계산됨
3. 전체 상품 데이터가 누락 없이 포함됨
