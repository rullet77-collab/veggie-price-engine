# 스프린트 S16: 통합 업로드 + 다운로드 UI

## 목표
한 화면에서 4개 플랫폼 업로드 파일을 생성/다운로드할 수 있는 통합 UI를 구현한다.

## 구현 범위
- [ ] /platform 페이지: 4개 플랫폼 카드 UI
- [ ] 각 플랫폼별 다운로드 버튼 (식봄/배민/온일장 → 엑셀, 신선행 → API)
- [ ] 다운로드 전 상품 수/변경 상품 수 미리보기
- [ ] 내비게이션 바에 "플랫폼 업로드" 링크 추가

## 합격 조건
1. /platform 페이지에서 4개 플랫폼 카드가 표시됨
2. 식봄/배민/온일장 다운로드 버튼 클릭 시 엑셀 파일이 다운로드됨
3. 신선행 카드에서 전송 대상 미리보기가 표시됨
